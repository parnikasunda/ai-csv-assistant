# AI-Powered CSV Assistant

An AI-powered CSV analytics assistant built using:
- Streamlit
- FAISS
- SentenceTransformers
- Python

## Features
- Upload CSV files
- Ask natural language questions
- Dataset summaries
- Salary analytics
- Interactive charts
- Chat-style interface

## Tech Stack
- Python
- Streamlit
- FAISS
- SentenceTransformers
- Matplotlib
